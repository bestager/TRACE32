1. Cursor AI란?

Cursor AI는 스타트업 Anysphere가 VS Code를 기반으로 만든 AI 네이티브 코드 에디터입니다. GitHub Copilot이나 Claude Code가 기존 에디터의 "플러그인"이라면, Cursor는 AI가 처음부터 내장된 독립형 IDE(통합 개발 환경)입니다. 자연어로 원하는 것을 설명하면 AI가 코드를 작성, 수정, 디버깅해줍니다.

쉽게 이해하기

VS Code가 "코드를 직접 쓰는 편집기"라면, Cursor는 "AI에게 말로 설명하면 코드를 대신 써주는 편집기"입니다. 마치 옆에 숙련된 개발자 친구가 앉아서 도와주는 것과 같습니다.

4. 첫 실행 및 초기 설정

코드베이스 인덱싱

프로젝트 폴더를 열면 Cursor가 자동으로 코드베이스를 인덱싱합니다. 이 과정에서 AI가 프로젝트 구조, 파일 관계, 코드 패턴을 학습합니다. 인덱싱이 완료되면 AI가 여러분의 프로젝트를 더 잘 이해하고 도와줄 수 있습니다.

프로젝트별 설정 파일

Cursor에서는 프로젝트별로 AI의 동작을 커스텀할 수 있습니다.

파일명설명
.cursorrulesAI에게 프로젝트별 지침을 제공 (예: "TypeScript를 사용해줘")
.cursorignoreAI 인덱싱에서 제외할 파일/폴더 지정 (예: node_modules, 빌드 결과물)
💡 초보자 팁: 처음에는 이 설정 파일 없이 시작해도 괜찮습니다. 프로젝트가 커지면 그때 추가하세요.

AI 모델 선택

Cursor 설정(Settings → Models)에서 사용할 AI 모델을 선택할 수 있습니다.

  • Claude Sonnet 4: 코드 이해력과 생성 능력이 뛰어남 (기본 추천)
  • GPT-4o: OpenAI의 최신 모델
  • cursor-small: 빠른 응답이 필요할 때 (자동완성에 적합)

초보자라면 기본 설정 그대로 사용하시면 됩니다.

5. 화면 구성 이해하기

Cursor는 VS Code와 거의 동일한 화면 구성에 AI 기능이 추가된 형태입니다.

기본 화면 구성

  • 사이드바 (왼쪽): 파일 탐색기, 검색, 소스 제어(Git), 확장 프로그램 관리
  • 편집 영역 (가운데): 코드를 작성하고 편집하는 주요 작업 공간
  • AI 채팅 패널 (오른쪽): Cmd+L (Mac) / Ctrl+L (Windows)로 열기
  • 터미널 (하단): Ctrl+`로 열기, 명령어 직접 실행
  • 상태 표시줄 (최하단): 현재 AI 모델, 사용량 정보 표시

6. 핵심 기능 살펴보기

6-1. Cursor Tab (AI 자동완성)

코드를 타이핑하면 AI가 다음에 올 코드를 자동으로 제안합니다.

  • Tab 키: 제안을 수락
  • Esc 키: 제안을 취소
  • 일반 자동완성과 다른 점: 프로젝트 전체 맥락을 이해하여 더 정확한 제안을 합니다.

6-2. 인라인 편집 (Cmd+K / Ctrl+K)

코드를 수정하고 싶을 때 사용하는 기능입니다.

  1. 수정하고 싶은 코드를 마우스로 선택합니다.
  2. Cmd+K (Mac) 또는 Ctrl+K (Windows)를 누릅니다.
  3. 작은 입력창이 나타나면 원하는 수정 내용을 자연어로 입력합니다.
    예: "이 함수에 에러 처리를 추가해줘"
  4. AI가 선택 영역을 자동으로 수정합니다.

6-3. AI 채팅 (Cmd+L / Ctrl+L)

채팅 패널에서 AI와 대화하며 코드를 작성할 수 있습니다.

예시 명령어:

  • "이 코드가 무슨 일을 하는지 설명해줘"
  • "로그인 API 엔드포인트를 만들어줘"
  • "이 함수의 버그를 찾아줘"
  • "단위 테스트를 작성해줘"

AI가 코드를 제안하면 "Apply" 버튼을 클릭하여 파일에 바로 적용할 수 있습니다.

6-4. 멘션(@) 기능

채팅에서 @를 입력하면 다양한 컨텍스트를 참조할 수 있습니다.

  • @파일명: 특정 파일의 내용을 AI에게 전달
  • @폴더명: 특정 폴더의 구조를 AI에게 전달
  • @웹주소: 웹 페이지 내용을 참조
  • @Docs: 공식 문서를 참조하여 답변

예시: @index.html 이 파일에 다크모드 토글 버튼을 추가해줘

6-5. 에이전트 모드

7. 첫 번째 프로젝트 만들기

실제로 간단한 프로젝트를 만들어보며 Cursor를 체험해봅시다.

예제: 간단한 계산기 웹앱 만들기

Step 1: 프로젝트 폴더 열기

  1. Cursor를 실행합니다.
  2. File → Open Folder를 클릭합니다.
  3. 새 폴더를 만들고 "my-calculator"라고 이름을 지어줍니다.
  4. 해당 폴더를 선택하여 엽니다.

Step 2: AI 채팅에서 작업 지시

Cmd+L (Mac) 또는 Ctrl+L (Windows)를 눌러 AI 채팅을 엽니다.

다음과 같이 입력합니다:

"간단한 계산기 웹앱을 만들어줘. HTML, CSS, JavaScript로 만들어줘. 사칙연산(더하기, 빼기, 곱하기, 나누기)이 가능하고, 깔끔한 UI로 만들어줘."

Step 3: AI의 응답 확인 및 적용

AI가 코드를 생성하면:

  1. 채팅 창에서 생성된 코드를 확인합니다.
  2. 코드 블록 옆의 "Apply" 버튼을 클릭합니다.
  3. 파일이 자동으로 생성되고 코드가 적용됩니다.
  4. Agent 모드에서는 파일 생성까지 자동으로 처리됩니다.

Step 4: 결과 확인 및 수정

  1. 생성된 index.html 파일을 우클릭 → "Open with Live Server" 또는 터미널에서 직접 브라우저로 열기
  2. 계산기가 제대로 동작하는지 테스트합니다.
  3. 수정이 필요하면 AI에게 추가 지시합니다.
    예: "배경색을 파란색으로 바꿔줘" 또는 "퍼센트 계산 기능도 추가해줘"

자주 묻는 질문 (FAQ)

Q: Cursor는 VS Code와 무엇이 다른가요?

A: Cursor는 VS Code를 기반(포크)으로 만들어져 외형은 비슷하지만, AI 기능이 처음부터 내장되어 있어 별도의 확장 프로그램 없이 AI 코딩이 가능합니다.

Q: 프로그래밍을 전혀 몰라도 사용할 수 있나요?

A: 네! AI에게 자연어로 지시하면 코드를 생성해줍니다. 다만 기초 개념을 알면 AI의 결과물을 더 잘 이해하고 활용할 수 있습니다.

Q: 한국어로 대화할 수 있나요?

A: 네, Cursor의 AI는 한국어를 완벽하게 이해합니다. 편하게 한국어로 작업을 지시하세요.

Q: VS Code 확장 프로그램을 사용할 수 있나요?

A: 네, Cursor는 VS Code 기반이므로 대부분의 VS Code 확장 프로그램과 호환됩니다.

Q: 인터넷 없이도 사용할 수 있나요?

A: 기본 코드 편집은 오프라인에서 가능하지만, AI 기능(자동완성, 채팅 등)은 인터넷 연결이 필요합니다.
